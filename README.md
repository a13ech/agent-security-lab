# Agent Security Lab

A hands-on workspace for researching agent security, exploitation techniques, defensive hardening, and agent framework experiments.

## Directory Structure

```
agent-security-lab/
├── exploits/          # Attack code and proof-of-concept exploits
├── defenses/          # Hardened implementations and mitigation strategies
├── frameworks/        # Agent framework experiments and analysis
└── notes/            # Documentation and research notes
```

## Quick Start

- **Exploits**: Add attack code and PoCs in `exploits/`
- **Defenses**: Implement hardened versions and defenses in `defenses/`
- **Frameworks**: Experiment with agent frameworks in `frameworks/`
- **Notes**: Document findings, research, and lessons in `notes/`

## Getting Started

1. Open this folder in VS Code: `code ~/agent-security-lab`
2. Start adding code and notes to each directory
3. Review the [Copilot instructions](.vscode/copilot-custom-instructions.md) for guidance
